# Freebuff Preferences

## User Shortcuts
- **sugf** = Execute ALL suggested followups (not just pick one)

## Project Context
- This is a Poly language compiler that transpiles to Rust
- The CLI binary is at `compiler/target/release/poly` or `compiler/target/debug/poly`
- Examples are in `examples/` directory
- Tests are in `compiler/crates/*/tests/`

## Preferences
- Prefer running tests after making changes
- Generate clean, formatted Rust output
- Always verify generated code compiles
