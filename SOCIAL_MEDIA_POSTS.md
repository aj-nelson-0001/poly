## LinkedIn Post

🎉 **Exciting Update for Poly Language Developers!**

We're thrilled to announce a significant syntax improvement in the Poly language: the new if statement syntax!

**Key Changes:**
✅ Comma replaces `then` keyword
✅ Single-line support for simple conditions
✅ Seamless else-if chains
✅ Nested conditions work beautifully

**Example:**
~~~
// Old syntax
if x > 0 then
    put x
end if

// New syntax
if x > 0,
    put x
end if
~~~

This change makes Poly code more concise and aligns with modern language design trends.

**Why the change?**
- More concise code
- Familiar to developers from other languages
- Reduces visual clutter
- Consistent with modern language design

## Reddit Post (r/programming)

**[Poly Language] New if statement syntax - comma instead of `then`**

Hey r/programming!

We just released a syntax update for the Poly language that changes how if statements work.

**Before:**
~~~poly fragment
if x > 0 then
    put x
else if x < 0 then
    put "negative"
else
    put "zero"
end if
~~~

**After:**
~~~poly
if x > 0,
    put x
else if x < 0,
    put "negative"
else,
    put "zero"
end if
~~~

The comma syntax is:
- More concise (no `then` keyword needed)
- Familiar to developers from Swift, Rust, etc.
- Cleaner visually
- Works great with else-if chains

We'd love to hear your thoughts! What do you think about this syntax change?

## Discord Announcement

📢 **Poly Language Update: New If Syntax!**

Hey everyone! 👋

We've just pushed a major syntax improvement to Poly: **if statements now use commas instead of `then`!**

**What's new:**
- `if condition,` instead of `if condition then`
- Single-line support: `if x > 0, put x`
- Clean else-if chains
- Better nested conditions

**Example:**
~~~poly
fn get_grade(score: i32): string
    if score >= 90,
        return "A"
    else if score >= 80,
        return "B"
    else,
        return "C"
    end if
end fn
~~~

This makes Poly code more concise and easier to read!
