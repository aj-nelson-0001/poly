# Archived Poly Documentation

This directory holds point-in-time documents kept for audit and migration reference. Nothing here is normative for the
current v2 preview. For current documentation start at [`../../POLY_DOCUMENTATION_INDEX.md`](../../POLY_DOCUMENTATION_INDEX.md)
or [`../../README.md`](../../README.md).

## What is here

- **Audit reports** — `AUDIT_REPORT.md`, `AUDIT_ROUND2_REPORT.md`, `PROJECT_AUDIT_REPORT.md`,
  `SECURITY_AUDIT_REPORT.md`, `SECURITY_FIX_HANDOFF.md`, `POLY_V2_AUDIT.md`. Each records the state of the tree on the
  date it was written; later fixes are not reflected.
- **v1 and guide-era manuals** — `POLY_LANGUAGE_SPECIFICATION_EXPANDED.md`, `THE_POLY_PROGRAMMING_LANGUAGE.md`,
  `The_Poly_Language_Guide.md` (and `.pdf`), `POLY_COMPREHENSIVE_GUIDE.md`, `POLY_BEST_PRACTICES.md`,
  `POLY_PERFORMANCE_GUIDE.md`, `POLY_SECURITY_GUIDE.md`, `POLY_DEPLOYMENT_GUIDE.md`, `POLY_INTEGRATION_GUIDE.md`,
  `POLY_COMPATIBILITY_GUIDE.md`, `POLY_VERSIONING_GUIDE.md`, `POLY_TESTING_GUIDE.md`, `POLY_PROFILING_GUIDE.md`,
  `HOW_TO_USE.md`. These describe earlier releases and older workflows.
- **Migration history** — `POLY_MIGRATION_GUIDE.md`, `POLY_MIGRATION_GUIDE_v1.8.md`, `POLY_FUTURE_MIGRATION_GUIDE.md`.
  Use the top-level `POLY_MIGRATION_GUIDE_v2.md` for current work.
- **Release and announcement material** — `RELEASE_NOTES_v1.6.0.md`, `RELEASE_PR_v2.0.0-preview.2.md`,
  `BLOG_POST_async_await.md`, `BLOG_POST_if_syntax.md`, `BLOG_POST_v1.5.0.md`, `SOCIAL_MEDIA_POSTS.md`, `whyPolly.md`,
  `freebuff-chat-2026-10-22T10-04-49.413Z.md`.
- **Superseded design records** — `POLY_JS_DESIGN.md`, `TRANSPILER_INTERMEDIATE_REPRESENTATION_REFACTORING_PLAN.md`.

## Policy

Archived files are not maintained. Fix a statement here only when it would actively mislead a current reader, or when a
current document needs to cite it. Link to an archived file by its full path from the repository root
(`docs/archive/NAME.md`) so the link resolves from anywhere.
