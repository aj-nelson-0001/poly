🎯 Clean Syntax

Poly uses a clean, readable syntax: var x i32 := 42, comma-based if conditions, and explicit end keywords. Operators are words — and, or, not, mod, xor, bitand, bitor, bitnot, shift left/right. No semicolons, no curly braces.

⚡ Fast Transpilation

Poly transpiles to idiomatic Rust through a shared intermediate representation pipeline — constant folding, inlining, and loop optimization included.

🛡️ Type Safety

Full static typing with a semantic checker that runs before code generation. Catch type mismatches at compile time, not runtime.
