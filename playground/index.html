🎯 Clean Syntax

Poly uses a clean, readable syntax inspired by Python, Ruby, and SuperBASIC. No semicolons, no curly braces.

⚡ Fast Transpilation

Poly transpiles to idiomatic Rust code, giving you all the performance benefits of Rust.

🛡️ Type Safety

Full static typing with type inference. Catch errors at compile time, not runtime.

🔄 Pattern Matching

Powerful pattern matching with guards, destructuring, and exhaustive checks.
